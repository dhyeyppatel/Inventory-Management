# Stockify - Inventory Management System

A full-stack inventory management web application built during Industrial Training (CE6008)
at **Appifly Infotech**, B.Tech Sem-8.

## Tech Stack
| Layer    | Technology                |
|----------|---------------------------|
| Backend  | Python 3, Django, MongoDB |
| Frontend | HTML5, CSS3, JavaScript   |
| Tools    | Git, GitHub, Figma        |

## Features
- Product management with image upload
- Multi-warehouse registration and stock tracking
- Stock movement with atomic transactions
- Forgot password via SMTP email tokens
- Admin console with CSV data export
- Supplier management with relational protection
- Order creation with barcode/SKU scanning
- PDF invoice generation
